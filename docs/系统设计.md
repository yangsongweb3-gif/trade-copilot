# trade-copilot 系统设计

> 交易副驾驶：只给信息和建议，方向盘永远在自己手里。

## 一、三条硬规则

1. **只做币安现货**，不碰杠杆和合约。
2. **系统永远不下单。** 买卖只由我自己在币安上操作；系统只负责获取数据、按规则提醒、AI 分析。
3. **币安 API Key 只开"读取"权限**（不开交易、不开提现），并绑定 IP 白名单。

## 二、模块

| 模块 | 职责 | 阶段 |
|---|---|---|
| 数据采集 `market` | 币安现货公开行情（24h 行情、K 线）；合约公开数据（资金费率、持仓量、多空账户比，只读） | 第 1 步 |
| 规则提醒 `rules` | 交易计划写在 YAML 里，判断买入区、止损、目标、取消条件、不追、均线规则 | 第 1 步 |
| 环境灯 `regime` | 汇总 BTC 趋势、波动、杠杆、美股、美元美债、稳定币、恐惧贪婪、BTC 现货 ETF 资金流（共八项）→ 🟢🟡🔴，只描述环境，不给操作建议 | 第 1 步 |
| 宏观数据 `macro` | Yahoo（纳指、美元、美债）、DefiLlama（稳定币）、alternative.me（恐惧贪婪）、CoinGecko（市值排名）、tftc.io（BTC 现货 ETF 资金流），全部免费公开 | 第 1 步 |
| 强势山寨 `scanner` | 市值 #5–#50、排除长期持仓（plans.yaml 的 `scanner.hold`）和稳定币，找近 7、14 天都跑赢 BTC 的币；参数在 plans.yaml 的 `scanner` | 第 1 步 |
| 关键价位 `levels` | 从均线、今日高低点、近 7/30 天波段高低点、整数关口里挑离现价最近的支撑和压力（纯函数） | 第 1 步 |
| 日程 `agenda` | 未来 7 天：ForexFactory 本周日历（美国中高影响数据）+ 美联储议息官方日程（`agenda.py` 里的表，每年初更新）；每个事件链接到官方发布页（BLS、BEA、美联储等），没收录的链接 ForexFactory 当天日历 | 第 1 步 |
| 今日变化 `changes` | 对比昨天列出变化：均线穿越、单日大涨跌、资金费率翻转、ETF 连续流入流出、恐惧贪婪换区、Coinbase 溢价翻转；有前一天快照时再加灯色和各项打分的变化 | 第 1 步 |
| 每日快照 `snapshot` | 每次生成页面都存 `data/snapshots/YYYY-MM-DD.json`（北京时间日期，同日覆盖）：灯色、综合分、各项打分、价格。用于今日变化、近 30 天灯色、以后回测 | 第 1 步 |
| Coinbase 溢价 `premium` | Coinbase BTC-USD 对比币安 BTC-USDT 的小时价差，近 7 天；不计入综合分 | 第 1 步 |
| 期权到期 `options` | Deribit 每周五 16:00（北京）到期：未平仓量、最大痛点、认沽/认购比，进"未来 7 天" | 第 1 步 |
| 日报图片 `report` | `python -m copilot.report`：临时起服务、把首页截成手机宽度长图（`?report=1` 去掉按钮和动画），写到 `.env` 的 `REPORT_DIR`；计划任务 `\TradeCopilot\btc-report` 每天 10:10 运行，10:30 由 my_invest_agent 的发群任务发到 QQ 群。数据拉不到就不出图 | 第 1 步 |
| 行业消息 `news` | PANews 中文快讯（按宏观、ETF、监管、安全等打标签）；币安公告的解析还在 `news.py` 里，首页不再显示 | 第 1 步 |
| 本地网页 `web` | 首页 `/`：今日变化、BTC 关键价位（支撑、压力）、环境灯（含近 30 天灯色，含灯色规则，以及 BTC 趋势、波动、杠杆、恐惧贪婪、ETF 五项的表格）、BTC 日线、宏观指标详细面板（纳指、美元/美债、稳定币：数值和涨跌、90 天走势、为什么看它、相关快讯；杠杆：资金费率柱状图、持仓量对比 BTC 价格、多空账户比；ETF：每日净流入柱状图、各基金明细；Coinbase 溢价：近 7 天小时柱状图。环境灯表格里的杠杆和 ETF 格子点击跳转到对应面板）、行业快讯（默认只看 BTC 相关）、未来 7 天日程（北京时间，含期权到期）；每块数据标注截至时间；`/alts`：强势山寨候选和全部扫描结果。双击 `start-web.bat` 打开 | 第 1 步 |
| 通知 `notify` | 按级别发到控制台 / QQ 私聊 / PushPlus | 第 1 步 |
| 状态 `state` | 记住已经提醒过什么，同一件事只提醒一次，状态变化才再提醒 | 第 1 步 |
| 账户同步 `account` | 只读 API 同步持仓、成交 | 第 2 步 |
| 交易日志 `journal` | 成交自动生成日志；检测"卖早""卖了又追高" | 第 2 步 |
| 存储 | PostgreSQL + pgvector（Docker） | 第 2 步 |
| AI 分析 `analyst` | 按研究清单分析新币、每日复盘、回答问题（DeepSeek） | 第 3 步 |
| QQ 问答 | 私聊里 `/持仓`、"ARB 怎么看" | 第 3 步 |
| 交易知识库 | 日志、复盘、研究导入 pgvector，按意思检索 | 第 4 步 |

## 三、消息怎么传

### 系统内部
第一版是**一个 Python 进程**，每轮流程：

```
market（拉行情） → rules（逐条计划判断，产出 Signal） → state（去重：只放行新的状态变化） → notify（按级别发送）
```

模块之间只传数据对象（`Ticker`、`Signal`），不互相调用内部细节。以后要拆成多个服务时，把这些对象改成通过 Redis 传递即可，格式不变。

### 今日环境灯

> 长期持仓不看这些。环境灯和强势山寨扫描是给山寨短线看的参考信息，**系统不给操作建议**，怎么做由自己判断。

`python -m copilot.main --regime` 生成一次（加 `--dry-run` 只打印）。建议每天北京时间 8:05（币安日线收盘后）定时跑。

| 灯色 | 条件 |
|---|---|
| 🔴 红灯 | BTC 空头排列（一票否决），或综合分 ≤ -2 |
| 🟡 黄灯 | 其他情况 |
| 🟢 绿灯 | BTC 多头排列，且综合分 ≥ 3 |

也可以双击 `start-web.bat`，在浏览器里看（默认 http://127.0.0.1:8000，只允许本机访问，数据缓存 10 分钟，页面上可手动刷新）。**放公网之前必须先加登录和 HTTPS**：以后页面会接持仓和计划。

每项打分 +1 / 0 / -1，BTC 趋势权重 ×2；数据拿不到的项不计分，报告里标 ❔。阈值在 `regime.py` 顶部，以后用回测调整。BTC 现货 ETF 资金流取自 tftc.io（Farside 有 Cloudflare 拦截），近 5 个交易日累计净流入超过 ±5 亿美元计 ±1。

### 发给我：三个级别

| 级别 | 什么情况 | 发到哪 |
|---|---|---|
| 🔴 紧急 `urgent` | 跌破止损、触发取消条件 | QQ 私聊 + PushPlus |
| 🟡 重要 `important` | 到达买入区、到达目标价、均线规则触发、不追提醒 | QQ 私聊 |
| 🟢 日常 `info` | 系统启动、每日汇总 | 控制台（以后加每日汇总） |

**隐私：持仓、计划、价位只发 QQ 私聊，永远不发群。**

## 四、目录

```
trade-copilot/
├─ config/plans.example.yaml   计划模板（提交到 git）
├─ config/plans.yaml           我真实的计划（不提交）
├─ .env                        NapCat、PushPlus、代理等本机配置（不提交）
├─ copilot/                    代码
│  ├─ config.py   加载 .env 和计划
│  ├─ market.py   币安行情（含合约资金费率、持仓量，只读）
│  ├─ macro.py    币安以外的宏观数据
│  ├─ regime.py   今日环境灯（纯函数，好测试）
│  ├─ scanner.py  强势山寨扫描（纯函数，好测试）
│  ├─ changes.py / snapshot.py  今日变化、每日快照
│  ├─ premium.py / options.py   Coinbase 溢价、期权到期
│  ├─ levels.py / agenda.py     关键价位、未来 7 天
│  ├─ report.py   每日日报长图（定时任务调用）
│  ├─ news.py     行业消息（币安公告、PANews）
│  ├─ web.py      本地网页（FastAPI）
│  ├─ static/     网页：index.html 首页、alts.html 强势山寨、style.css 和 common.js 两页共用
│  ├─ rules.py    规则判断（纯函数，好测试）
│  ├─ state.py    提醒去重
│  ├─ notify.py   发通知
│  └─ main.py     主循环
├─ start-web.bat               双击启动本地网页
├─ tests/                      规则、环境灯的单元测试
└─ docs/系统设计.md             本文件
```
